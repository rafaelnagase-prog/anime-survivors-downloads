# Anime Survivors

Distribuição da edição Amigos para Windows.

[Baixar a versão mais recente](https://github.com/rafaelnagase-prog/anime-survivors-downloads/releases/latest/download/AnimeSurvivors_para_amigos.zip)

Extraia o pacote e abra **AnimeSurvivors_Launcher.exe**. O launcher verifica as novidades ao abrir; clique em **Atualizar** quando uma versão estiver disponível.

Os downloads são públicos e não exigem conta GitHub. O progresso e as configurações continuam no computador do jogador. Para jogar online, todos devem atualizar o jogo para a mesma versão.

Este repositório distribui o jogo compilado. Não contém o código-fonte, ferramentas administrativas, saves ou chaves privadas do desenvolvedor.
